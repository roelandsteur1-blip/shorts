Privacy policy – shorts-pipeline

shorts-pipeline is a personal tool that uploads videos to the owner's own YouTube channel (spacefactoidss). It is used only by its owner.

  • Data accessed: with your permission it uses the YouTube Data API to upload videos and read basic channel and video information, and the YouTube Analytics API to read view statistics for your own videos.
  • Storage: the login token and all data stay on the owner's own computer. Nothing is sent to any server other than Google's.
  • Sharing: no data is sold or shared with third parties.
  • Revoking access: you can remove access at any time at https://myaccount.google.com/permissions.

    • The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
